# Эксперимент с ценами площадок GGL

Цель: понять, какая цена размещения даёт лучший результат по продажам,
выручке и прибыли.

## Участники

- Домены с `domain.ggl_trust = 9`, не удалённые и не проданные (на 28.10.2026 их 48).
- `target = 'site'` — группа `control`. Цены не меняем, только проверяем, что
  каждая включённая цена не ниже 900 ₽. Нарушения выводятся списком «домен — цена».
- Остальные (`gensite`) делятся на три группы с ценой 500, 450 и 400 ₽.
  Цена одна на все три типа: статья, заметка, контекстная ссылка.
- Группы выравниваются по продажам за 90 дней до старта: домены сортируются
  по продажам и раздаются змейкой (A B C C B A …).
- 28.10.2026 четыре `site` с ценой ниже 900 перенесены из контроля в группы:
  shtrafsud.ru → 450, ohranatryda.ru → 400, aqueo.ru и wallpanels.ru → 500.
  Итог: 500 — 15 доменов, 450 — 14, 400 — 14, control — 5 (все от 900 ₽).

## Где цены на GGL

`/mySites` → «Настроить» в первом столбце → карточка сайта
`/editSiteInfo/index/site_id/<id>`. Поля `#price_paper`, `#price_post`,
`#price_link`, флажки «не размещаю» `#not_price_*`. Сохранение:
`POST /editSiteInfo/updateValue` со **всеми** полями карточки, поэтому
сохраняем через собственную форму GGL (открыть окно, поменять три цены, нажать
«Сохранить настройки»). Остальные настройки уходят такими, как были.

## Таблицы (`schema.sql`)

- `ggl_price_experiment`: домен, `site_id`, группа, целевая цена, продажи
  до старта, `applied_at` (выставлено и проверено перечитыванием).
- `ggl_site_prices`: история прочитанных цен.

## Команды (только вручную, в кроне их нет)

```bash
venv/bin/python gogetlinks_parser.py --prices-assign          # один раз: группы
venv/bin/python gogetlinks_parser.py --prices-read            # прочитать цены
venv/bin/python gogetlinks_parser.py --prices-apply           # что будет изменено
venv/bin/python gogetlinks_parser.py --prices-apply --confirm # записать на GGL
venv/bin/python gogetlinks_parser.py --prices-report          # итоги по группам
```

`--prices-read` и `--prices-apply` берут тот же lock, что и этап `/mySites`.

## Отчёт

Период — от первого `applied_at` до текущего момента; группы сравниваются
между собой за этот период, «до» не считаем. Продажи и выручка берутся из
`ggl_tasks` (`price > 0`). Затраты: 120 ₽ за задание «Статья», «Заметка» или
«Контекстная ссылка».
